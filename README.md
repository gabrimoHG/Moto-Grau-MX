# Moto Grau MX (Motorbike wheelie game)
This was my last attempt as a freelance game developer where I created almost everything from scratch. Except for the physics base, which I customized a lot, everything else have been created by me,
including the UI/UX, audio, the map and the models. It was also a good way for me to implement Google AdMob in a project, as well as to pass by the hurdles to release it in the Google Play Store.

## 🎮 Key Features

- Realistic motorbike physics, including acceleration and top speed according to the models both bikes available are based on.
- A free roam map for the player to explore based on a Rio de Janeiro neighborhood.
- Interactive elements like gates and ramps, allowing unique access to certain parts of the scenario.
- Fuel and damage systems linked with specific AdMob responses, creating a reason for most valuable Ads to be played.
- Pick ups to fix/refuel the bike.
- In-game bike change module, letting the player find new bikes to ride in.
- Scrapeable bike tail implementation with sparks particles, the tail also breaks after a certain amount of contact

## 🛠 How to Run
Unity version: 2022.3.39f1

Open the `MainMenu` scene and press Play
